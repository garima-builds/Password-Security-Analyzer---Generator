# 🔐 Password Security Analyzer

A simple web-based application that analyzes password strength and generates strong random passwords.

## 📌 About the Project

Password Security Analyzer helps users understand the basic security characteristics of a password.

The application checks the password for important characteristics such as length, uppercase letters, lowercase letters, numbers, and special characters.

It also includes a strong password generator that creates a random password using different types of characters.

## ✨ Features

- 🔍 Password strength analysis
- 📊 Security score
- 📏 Password length check
- 🔠 Uppercase letter check
- 🔡 Lowercase letter check
- 🔢 Number check
- 🔣 Special character check
- 🔑 Strong password generator
- 👁️ Show/Hide password option
- 💡 Password security tips
- 📱 Responsive web interface
